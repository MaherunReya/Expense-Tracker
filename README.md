# Expense Tracker

## Description
This is a simple **Expense Tracker** application designed to help users manage and monitor their daily expenses. Users can add, edit, and delete expenses, categorize them, and get a summary of their spending patterns.

## Features
- Add, edit, and delete expenses
- Categorize expenses (e.g., Food, Transport, Bills)
- View total expenses and expense summaries
- Enhanced charts
- Monthly and yearly reports
- Export expenses as CSV
- Bills tracker
- Debt tracker
- Responsive design for desktop and mobile


## Installation
Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/username/Expense-tracker.git

# Navigate into the project folder
cd expense-tracker

# Install dependencies 
npm install

# Start the application
npm start dev
